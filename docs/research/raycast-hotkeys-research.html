Raycast 用户最常用的快捷键和设置：调研报告

写于 2026-10-17。用 4 个 subagent 分头调研（英文社区、X / Hacker News / 博客、中国大陆平台、Raycast 官方资料和同类工具），一共看了大约 80 个网页。最后一部分是根据调研结果给 HyperCapslock 的建议。

1. 一句话结论

几乎每个 Raycast 重度用户都会做三件事：

  1. 用 Hyper 键加 App 名字的首字母，一键打开或切到某个 App（Hyper 键的意思是：按下 CapsLock 就相当于同时按住 ⌃⌥⌘ 或 ⌃⌥⌘⇧ 这几个修饰键，这样组合出来的快捷键几乎不会跟别的软件冲突）。HyperCapslock 已经有「打开应用」这个动作。
  2. 窗口管理：把窗口放到左半屏、右半屏、最大化、居中、移到另一块显示器。HyperCapslock 目前没有这类动作，这是最大的空缺。
  3. 剪贴板历史：多数人绑在 Hyper+V 或 ⌘⇧V 上。HyperCapslock 不需要自己做剪贴板历史，但可以把 Caps+V 默认绑到「发出某个剪贴板软件的快捷键」上。

另外，中国用户有一个英文社区里很少见的需求：按一个键直接切到指定的输入法（不是在几个输入法之间轮换）。HyperCapslock 已经有这个功能，而且做得比 Raycast 自带的更完整。

2. 调研范围，以及哪些平台没查到

有三个平台基本没拿到内容，结论的代表性因此有限：

  • Reddit：一条帖子也没读到。搜索工具在服务器那一端就拒绝了 reddit.com；网页抓取、Reddit 的 JSON 接口、RSS、存档网站 PullPush 也都被拦了；Reddit 的镜像网站都要先过人机验证，我们没有去绕过人机验证。作为替代，用了性质最接近的几个社区：Hacker News 的评论、Mac Power Users 论坛、Raycast 官网上的用户故事、个人博客里贴出的完整配置。如果你一定要 Reddit 原帖，可以在浏览器里打开帖子把内容贴给我，或者申请 Reddit 官方 API 的密钥。
  • X / Twitter：一条推文也没搜到。限定在 x.com 的搜索只返回 Raycast 的官方手册和更新日志。
  • 小红书、知乎、B 站：基本没看到正文。小红书没法检索；知乎专栏打开时返回 403（被拒绝访问）；B 站只看到视频简介，简介里没写具体按键。中文这一块的结论主要来自 V2EX、少数派和个人博客。

其他需要注意的地方：

  • 样本小，而且偏开发者。英文这边一共大约 15 份具体配置，中文这边大约 20 个页面。愿意公开分享配置的人本来就是重度用户，普通用户可能只用 ⌘Space 呼出 Raycast 和剪贴板历史。
  • 下文的「很多 / 一些 / 少量」是按看到的来源数估的，不是统计结果。
  • Raycast 官方没有公布过「全体用户最常用哪些命令」的数据。Raycast 的年度回顾（Wrapped）的数据只存在每个人自己的电脑上，Raycast 公司自己也拿不到。唯一能拿到的数字是 Raycast 扩展商店里每个扩展的安装量。
  • Raycast 自带 Hyper Key 是 2025 年 2 月（v1.91.0）才上线的。很多「字母对应 App」的习惯来自更早的 Karabiner（改键工具）和 Hammerspoon（用脚本写快捷键的工具）用户，是同一类人的习惯，可以参考，但不完全是 Raycast 用户。

3.2 推荐打开的设置

  • 把 CapsLock 设成 Hyper 键：几乎所有人都推荐，理由基本都是「反正我从来不用 CapsLock」。
  • 单独轻按一下 CapsLock 时发出 Escape：程序员里非常普遍，HN 上至少 5 个人提到。另一种做法是单独轻按时仍然是大小写锁定。还有一个少见的配法：轻按发出 ⌘T。
  • Hyper 键要不要包含 Shift：有人更喜欢不带 Shift 的 ⌃⌥⌘，这样需要时再加 Shift 就多出一层快捷键。
  • 把原来的大小写锁定挪到别的键上，比如右 Shift。

3.3 几段原话

「Hyperkey + V opens Raycast's clipboard manager (V because I'm pasting)」——Mac Power Users 论坛用户。同一个人还配了 D 打开 Dia 浏览器、N 打开 Drafts、T 打开 Things、A 打开 Claude、F 开关专注模式。
Brian Lovin：✦S Slack、✦D Dia、✦F Figma、✦G Ghostty、✦N Notion、✦M Messages、✦P 1Password、✦C Calendar。「you'll never want to use your dock or the command + tab UI ever again」。
James Mulholland（Raycast 用户故事）：用 ✦H/J/K/L 把窗口放到左、下、上、右半屏，✦M 最大化，「match the keybindings to Vim」。他每天用剪贴板历史大约 100 次。
HN 用户：「I have Capslock + A assigned as the hotkey and have superfast AI at my fingertips」。
HN 用户：「capslock key is now a hyperkey when pressed and ⌘T when tapped」（按住是 Hyper 键，轻按是 ⌘T）。

4.2 字母对应 App 的中文习惯

  • W 几乎总是微信。好几个配置都是这样（xxhk.org 的博客、Ruby China 的 Hammerspoon 指南、forecho 的博客）。这是中文社区最稳定的一个约定。
  • Q 是 QQ 或企业微信；企业微信有时放在 Y 或 0 上。
  • C 和 G 是 Chrome（C 有时也是代码编辑器），S 是 Safari，I 和 T 是终端（iTerm、Terminal）。
  • 没有看到飞书、钉钉有固定的字母。

4.3 中国用户特有的需求

  1. 按一个键直接切到指定的输入法，不来回轮换。V2EX 帖子里的原话：「我们只需要中英两种输入状态」。常见做法是左 ⌘ 切英文、右 ⌘ 切中文，也有人按当前 App 自动切（终端里英文，聊天软件里中文）。有三个以上输入法时，有人用 Kawa 或 Input Source Pro 这类专门的工具。
  2. 打开 Raycast 时自动切到英文输入法。少数派的指南专门讲了 Raycast 设置里的 Auto-switch Input Source，原因是在中文输入法下搜命令很别扭。
  3. CapsLock 切中英文有延迟。小红书上流传 hidutil property --set '{"CapsLockDelayOverride":0}' 这条命令来去掉延迟（这一条来自搜索摘要，原帖没打开过）。
  4. Raycast 的 Hyper Key 和「CapsLock 切输入法」冲突。CapsLock 被 Hyper Key 占用后，轻按 CapsLock 只能选「什么都不做 / 原来的 CapsLock / Escape」，想同时用 CapsLock 切输入法的用户会很别扭。

4.4 几段原话

V2EX：「CapsLock 改成 Control ⌃ 和 Esc ⎋ ……算是较为公认的最佳改键方案了」。（v2ex.com/t/565667）

5. Raycast 官方资料和同类工具的默认设置

5.1 Raycast 自带 Hyper Key 有哪些选项

选项内容
用哪个物理键当 Hyper 键CapsLock、任意一个左或右修饰键、F1–F12
Hyper 键等于哪几个修饰键默认 ⌃⌥⌘（不带 Shift）；打开 Include Shift 后是 ⌃⌥⌘⇧。Karabiner 和 Hyperkey 的默认是带 Shift 的四个键。
Quick Press（单独轻按一下时做什么）什么都不做 / 发出原来的 CapsLock / 发出 Escape
Secure Input 兼容（默认关）Secure Input 是 macOS 的安全输入模式，比如光标在密码框里时会打开，打开后第三方程序收不到按键。打开这个选项后，Raycast 的 Hyper 快捷键在 Secure Input 期间也能用，代价是右 Control 键被占用。
Hyper Key 诊断面板检查跟 Karabiner、系统设置里的 CapsLock 映射有没有冲突，可以不退出 Raycast 就重启 Hyper Key。

和 HyperCapslock 的关系：工程里正在做的 Secure Input 提醒（SecureInputMonitor.swift）和 Raycast 的这两个功能方向一致，可以对照着看。

5.2 Raycast 内置的、常被绑快捷键的命令

Raycast 官方没有给这些命令设默认快捷键，手册里让用户自己给常用的命令绑快捷键。

  • 窗口管理：左半 / 右半 / 上半 / 下半屏、最大化、接近最大化、合适大小、居中、恢复原来大小、全屏、三等分、四个角、移到上一个或下一个显示器、移到上一个或下一个桌面。
  • 剪贴板历史：打开历史、按顺序依次粘贴、去掉格式后粘贴。
  • 系统命令：锁屏、睡眠、关闭显示器、切换深色 / 浅色模式、显示桌面、清空废纸篓、推出所有磁盘、退出所有 App、隐藏其他 App、开关蓝牙、播放 / 暂停、上一首 / 下一首、静音、调音量。
  • 其他：搜索当前 App 的菜单项、切换窗口（打字搜索所有窗口）、表情符号、笔记、翻译、截图、计算器。

5.4 同类工具的默认设置

  • Rectangle（窗口管理）的默认快捷键：⌃⌥←/→/↑/↓ 放半屏，⌃⌥Enter 最大化，⌃⌥C 居中，⌃⌥⌘←/→ 移到上一个或下一个显示器，⌃⌥Delete 恢复原来大小。连按同一个键会在 1/2、2/3、1/3 之间轮换。这套快捷键就是上面中文社区说的「⌃⌥+方向键」习惯的来源。
  • Karabiner 社区规则库里 CapsLock 相关的规则：CapsLock 变 Hyper，单独按时发 Escape；CapsLock 变 Control，单独按时发 Escape；用 Shift+CapsLock 当真正的大小写锁定；按住 CapsLock 时 IJKL 当方向键；用 CapsLock 切换输入法；连按两次 Shift 开关大小写锁定。
  • Hyperkey（Rectangle 作者写的小工具）：把 CapsLock 变成 ⌃⌥⌘⇧，轻按可以发 CapsLock 或 Escape，官网承认在密码框里不能用。

7. 和 HyperCapslock 现有功能对比

HyperCapslock 现在能做的动作：光标移动（上下左右、按单词、行首行尾）、跳 10 行、删除、新起一行、插入引号、开关大小写锁定、切换到指定输入法、发出组合键、运行 shell 命令、打开应用、按住某个修饰键。触发方式有 Caps+键、Caps+Shift+键、轻按 Caps、连按两次 Caps、连按两次某个修饰键，并且可以按当前 App 给同一个键配不同的动作。

大家常用的功能HyperCapslock 现在说明
Hyper+字母 打开 App已有「打开应用」动作。App 没装时只写一行日志，什么都不发生，界面上也不报错。
打开 App 时，如果它已经在最前面就把它隐藏（中文帖子里「打开或隐藏微信」）没有现在只会把 App 切到前面，再按一次不会隐藏。
窗口管理（半屏、最大化、居中、移到另一块显示器）没有只能通过「发出组合键」去触发 Rectangle 之类的另一个软件。这是最大的空缺。
剪贴板历史间接可以可以用「发出组合键」触发别的剪贴板软件（比如你的 PastePaw）。不建议自己做一个剪贴板历史。
切换到指定输入法已有，而且比 Raycast 强Raycast 只能在打开 Raycast 时自动切英文；HyperCapslock 可以把任意键绑到任意输入法，还处理了中日韩输入法切换不生效的问题。
轻按 CapsLock 发 Escape能配，但不好找现在轻按 CapsLock 默认是开关大小写锁定。更正：HyperCapslock 运行时，系统设置里的「用 CapsLock 切换输入法」不会生效，因为 CapsLock 已经被改成 F18，系统收不到 CapsLock 按键（Frank 核实，见工程提交 1e3f462 的实验记录）。用户可以给「轻按 Caps」这个触发方式绑一个「发出组合键 Esc」，但需要自己去找，不像 Raycast 那样是一个现成选项。
Caps+没有映射的键 → 发出 ⌃⌥⌘+这个键（让别的软件也能用 Hyper 快捷键）没有现在 Caps+没有映射的键会把这个键原样放过去。Raycast、Karabiner、Hyperkey 的 Hyper 键都是这样工作的，用户可以在任何软件里设置 Hyper 快捷键。
系统命令（锁屏、睡眠、深色模式、清空废纸篓、媒体控制、音量）部分可以锁屏可以用组合键 ⌃⌘Q，其他的可以用 shell 命令凑出来，但没有现成的动作。
截图已有刚加的默认键位 Caps+4 → ⇧⌘4。
打开某个文件夹或网址能凑出来用 shell 命令 open ~/Downloads 可以做到，但没有现成的动作。

8. 建议

8.1 默认键位（新用户第一次安装时的映射）怎么调整

和刚才提交的那一版默认键位（C Chrome、F Finder、T Terminal、X Xcode、N Notes、S Safari、4 截图）对比：

按键建议理由
Caps+B新增：打开系统默认浏览器上次你提到 B 但没说对应哪个 App。调研里「B = 浏览器」是很稳定的约定。可以在第一次生成默认配置时，查一下用户的默认浏览器是哪个，把它的 bundle id 写进去，这样不需要新增动作类型。
Caps+W新增：打开微信（com.tencent.xinWeChat）中文社区最稳定的约定。没装微信时按了什么都不发生，界面上也不报错，对外国用户没有坏处。
Caps+T保留：终端两边社区都最稳定。
Caps+N保留：备忘录「N = 笔记」很稳定。
Caps+X保留：XcodeRaycast 官方手册就是用这个当例子的。
Caps+C、Caps+S、Caps+F保留C 和 S 各有两派说法，但 Chrome、Safari、Finder 是最大众的选择。
Caps+4保留：截图—
Caps+V先不放默认大家都习惯 V 是剪贴板历史，但 HyperCapslock 自己没有剪贴板历史，不知道用户用的是哪个剪贴板软件。建议把 V 留空，等用户自己绑。

8.2 新增动作（按优先级排）

优先级 1：窗口管理动作。这是调研里最常用、而 HyperCapslock 完全没有的功能。用 macOS 的辅助功能接口（Accessibility API）移动和缩放当前窗口；HyperCapslock 本来就需要辅助功能权限，不需要用户再多授权一次。

第一批只做最常用的几个（少数派作者原话：常用的「只有左半屏、右半屏、最大化以及窗口居中这四个」）：

  • 左半屏、右半屏、最大化、居中
  • 移到下一个显示器
  • 恢复原来大小
  • （可选）连按同一个键在 1/2、2/3、1/3 宽度之间轮换（Rectangle 的做法）

默认键位的问题：英文社区有人用 Caps+H/J/K/L 管窗口，但 HyperCapslock 的 H/J/K/L 已经是方向键，而且这是核心功能，不能动。建议用 Caps+Shift+H/L（左右半屏）、Caps+Shift+K（最大化）、Caps+Shift+J（居中），或者用 Caps+[ / ] / \（英文社区里也有人这样配）。窗口管理的默认键位要不要放，建议你先试用一下再定。

注意：新增的动作要加新的 builtin.* 编号，按工程规则这些编号以后不能改名也不能删。

优先级 2：把「轻按 CapsLock 做什么」做成设置页里的一个现成选项。

现在的逻辑（ActionExecutor.fireCapsShortTap）：

如果 用户给「轻按 Caps」配了动作:
    执行这个动作
否则:
    开关大小写锁定（通过 IOKit；系统设置里的「用 CapsLock 切换输入法」此时不会生效）

建议在设置页加一个选项，可选：开关大小写锁定（默认，保持现在的行为）/ 发出 Escape / 什么都不做。不建议把默认改成 Escape。更重要的是：中文用户里最多的人用 CapsLock 切中英文，而 HyperCapslock 运行时系统原生的这个切换是失效的，所以应该另外提供「轻按 Caps 切换中英文」的选项（Raycast v0.55 也是自己实现的）。

优先级 3：「打开应用」加一个「如果已经在最前面就隐藏」的开关。

按下 Caps+W 时:
    如果 微信已经是最前面的 App 并且打开了这个开关:
        隐藏微信
    否则:
        打开微信或切到微信

中文帖子里多次提到「打开或隐藏微信」，Hammerspoon 的配置也常这样写。

优先级 4：Caps+没有映射的键 → 发出 ⌃⌥⌘（或 ⌃⌥⌘⇧）+这个键（做成可选设置，默认关）。

这样用户可以在 Raycast、Alfred 或者任何软件里设置「Hyper 快捷键」，HyperCapslock 就同时具备了 Raycast Hyper Key 的能力。从 Raycast Hyper Key 换过来的用户也不用重新配快捷键。默认关的原因是：有用户可能依赖现在「没有映射的键原样放过去」的行为。

优先级 5：一组现成的系统动作。锁屏、睡眠、关闭显示器、切换深色 / 浅色模式、显示桌面、播放 / 暂停、上一首 / 下一首、静音、调音量、清空废纸篓。这些现在都能用组合键或 shell 命令凑出来，但普通用户不会写。做成内置动作后，在动作列表里直接选就行。

优先级 6：「打开文件夹」和「打开网址」动作。英文社区有人用 ✦D 打开下载文件夹、✦W 打开工作目录；Quicklinks（一键打开网址）是 Raycast 最常被谈论的功能之一。现在可以用 shell 命令 open 做到，做成内置动作只是更方便。

8.3 不建议做的

  • 剪贴板历史、Snippets、翻译、AI 对话：这些是 Raycast、PastePaw、Easydict 这类软件的本职工作，HyperCapslock 自己做会变成另一个 Raycast。更好的做法是让 HyperCapslock 用「发出组合键」去触发这些软件。
  • 把 H/J/K/L 让给窗口管理：H/J/K/L 当方向键是 HyperCapslock 的核心功能。
